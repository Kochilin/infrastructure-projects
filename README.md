## Publication boundaries

These are sanitized technical summaries, not deployment guides. They omit live configurations, addresses, hostnames, serial numbers, identifying site details and client identifiers. Diagrams describe logical responsibilities rather than exact cabling or sensitive network topology. Claims about implementation and validation are separated where appropriate.
